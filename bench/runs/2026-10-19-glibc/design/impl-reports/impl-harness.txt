SUMMARY: The harness now runs on Linux. I changed three repo files, all LF with CR=0: test/native/smoke-test.sh (814 lines, +111/-22 in the diff), test/native/OcljSmoke.scala (7041 lines, one message changed) and test/native/LinkProbe.java (99 lines, one usage string changed).

What smoke-test.sh does now:
- **Platform from uname.** It reads the host the same way build-native.sh does (windows under MINGW/MSYS/CYGWIN/Windows_NT, linux on Linux, x86_64 only). The library name, the patcher binary (luajit.exe on Windows, luajit on Linux) and the path plumbing all come from that host value.
- **Plumbing keyed on the host.** It no longer depends on whether cygpath happens to be on PATH. On Windows a missing cygpath now fails with a message.
- **Patcher lookup.** The default is <libdir>/../luajit-<platform>/src/luajit[.exe], with the older luajit/src/ layout as a fallback. On Linux it refuses a Windows PE by its first two bytes ("MZ"), and the patcher-failure message now names the binary as a possible cause.
- **Benchmark directory.** The default is bench/oc when the caller stands in the repository, which is unchanged on Windows. Otherwise it is this checkout's bench/oc, absolute. A missing mandelbrot.lua is refused before the JVM starts.
- **Docs.** The header has updated docs and a new HOST PLATFORMS section.

Two scratch launchers are written and tested:
- **full-linux.sh** reads the distro and picks the JDK: AlmaLinux gets JDK 8u504, Ubuntu gets JDK 17. It pins a Linux-only PATH, runs the JVM in a per-run working directory, resolves and test-runs the patcher's luajit, records each .so's glibc needs, and refuses an unrunnable arm before the harness starts.
- **chain-linux.sh** runs chain-r3's seven arms. It was verified against a stub launcher, not as a real chain.
