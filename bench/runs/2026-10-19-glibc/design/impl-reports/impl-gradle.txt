SUMMARY: The glibc gate is in build.gradle.kts's verifyModAssets and has been verified with the real task, `./gradlew --offline --no-daemon verifyModAssets -Pocljit.nativesDir=<scratch>`, on 35 natives directories. Nothing under build/native was used or written.

The gate reads every packaged .so itself, with no binutils: the ELF64 header, the section headers, the one .gnu.version_r with its Verneed/Vernaux chains, and names from the string table that sh_link points to. It refuses the build with a GradleException in the existing style when any GLIBC_x.y need is above the floor, when any need is not a GLIBC_x.y release version (GLIBC_PRIVATE, GCC_*), or when the file does not parse. Every read is bounds-checked and every loop is bounded, so a bad file is refused with a reason and never ends in an exception or a hang. When a .so passes, a lifecycle line names its highest need.
